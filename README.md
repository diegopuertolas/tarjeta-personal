# Tarjeta Personal
## Diseño de Interfaces Web

### Desafío HTML

- Crea un contenedor principal que represente la tarjeta.
- Incluye una imagen de perfil  con su atributo alt.
- Añade un títulocon el nombre y un párrafo  con una breve biografía.
- Agrega una lista no ordenada con al menos 3 habilidades o pasatiempos.
- Incluye un enlace a un perfil ficticio o red social.

### Desafío CSS:

- Cambia el fondo de la página (background-color) y aplica una tipografía sin serifa (font-family: sans-serif) al cuerpo.
- Limita el ancho de la tarjeta (max-width: 300px), céntrala en la pantalla utilizando márgenes y añade un borde con esquinas redondeadas (border-radius).
- Haz que la imagen sea completamente circular (border-radius: 50%) y ajusta su tamaño.

### Reto Extra
- Añade una pseudo-clase :hover al enlace para que cambie de color y pierda el subrayado al pasar el ratón.
